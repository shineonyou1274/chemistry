# 화학 바이브코딩 실습장

화학교육과 마이크로 디그리 연수(7시간)용 단계별 실습 사이트.

연수생은 화학 교사다. 이 사이트의 목적은 도구 사용법 전수가 아니라,
**"AI에게 일을 시키는 법"과 "학생에게 과제를 내는 법"이 같은 구조라는 것**을
직접 겪게 하는 것이다. 마지막 워크벤치에서 대상이 AI에서 학생으로 뒤집히고,
그 순간 산출물 3종이 나온다.

순서는 **보여주고 → 궁금하게 하고 → 시키는 법을 주고 → 검증시키고 → 바꾸게 한다.**

---

## 여는 법

`index.html`을 브라우저로 열면 된다. 빌드도 설치도 없다.

다만 세트 S1의 완성본은 `<iframe>`으로 붙어 있어서, `file://`로 열면
브라우저에 따라 프레임이 비어 보일 수 있다. 그럴 때는 이 폴더에서
정적 서버를 하나 띄운다.

```
npx http-server -p 8080 .      # 또는  python3 -m http.server 8080
```

**GitHub Pages로 올리면 이 문제가 없다.** 저장소 Settings → Pages에서
Source를 이 브랜치의 루트로 지정하면 `https://<사용자>.github.io/chemistry/`
주소가 나오고, http로 서빙되므로 iframe이 정상 동작한다.
반대로 github.com에서 `index.html`을 클릭해 보는 것이나 `raw.githubusercontent.com`
주소는 소스만 보여 줄 뿐 실행되지 않는다.

인터넷이 없어도 전부 동작한다. 외부 의존은 본문 서체(Pretendard) CDN 한 줄뿐이고,
연결되지 않으면 시스템 서체로 조용히 내려간다.

## 보기 모드 — 가로가 기본

세로로 길게 흐르면 관찰과 기록이 멀어진다. 그래서 기본은 **가로 보기**다.

* **↔ 가로** (기본) — 한 화면에 한 단계만. 왼쪽 관찰 칼럼과 오른쪽 기록 칼럼이
  각각 따로 스크롤되고, 페이지 자체는 스크롤되지 않는다. 단계 이동은
  **← → 키**, 위쪽 단계 칩, 아래쪽 이전·다음 버튼 셋 다 된다.
  (글을 쓰는 중에는 화살표 키가 단계를 넘기지 않는다.)
* **↕ 세로** — 다섯 단계를 죽 펼쳐 훑는 아코디언. 전체를 한눈에 보거나
  인쇄할 때 쓴다. 이때도 왼쪽 관찰 칼럼은 한 화면 높이로 묶여 있다.

상단 오른쪽 버튼으로 언제든 바꾸고, 고른 모드는 진행 저장 JSON에 함께 담긴다.
화면이 좁으면(900px 이하) 가로 보기도 자동으로 한 단으로 쌓이고,
상단 메뉴는 가로로 밀어서 본다.

## 저장

**브라우저 저장소를 쓰지 않는다.** localStorage·sessionStorage·쿠키 어느 것도
건드리지 않으므로, 공용 PC에 연수생의 입력이 남지 않는다.

* **진행 저장** — 입력 전체를 JSON 파일로 내려받는다
* **이어서 하기** — 그 JSON을 불러와 잠금 상태까지 그대로 복원한다
* 5분마다 "저장하셨나요" 알림이 뜬다. **고친 것이 있을 때만** 뜬다
* 저장하지 않고 창을 닫으려 하면 브라우저가 되묻는다. 저장한 뒤에는 되묻지 않는다

파일을 잘못 골랐을 때를 대비해 두 겹으로 막아 두었다.

* 저장 파일에 `kind: "chem-vibecoding-progress"` 표시를 넣고, 불러올 때 확인한다.
  다른 JSON을 고르면 **아무것도 바꾸지 않고** 거절한다
* 지금 화면에 고친 것이 있으면 덮어쓰기 전에 되묻는다

`file://`로 열어도, GitHub Pages로 올려도 저장과 불러오기는 똑같이 동작한다.
한글·이모지·줄바꿈·따옴표가 그대로 오간다. 다만 내려받는 파일명은
일부 브라우저가 비ASCII 이름을 `download`로 바꿔 버려서 영문으로 두었다.

## 잠금 규칙

각 단계 머리에 그 단계의 완료조건이 **항상 보인다.** 잠긴 이유도 숨기지 않는다.
잠금 자체가 오늘 배울 프레임의 시연물이다.

| 전이 | 완료조건 |
|---|---|
| S1 → S2 | 관찰 메모 20자 이상 + "학생이 가장 먼저 물을 질문" 10자 이상 |
| S2 → S3 | 완료조건 체크박스 전 항목 확인 |
| S3 → S4 | 사용한 AI 도구 선택 + 생성 결과 소감 20자 이상 |
| S4 → S5 | 발견한 오류 2건 이상 기록 (각 건마다 "어긋난 완료조건" 지정 필수) |
| S5 → 다음 세트 | 진도표 위치 입력 + 변형 계획 20자 이상 |

잠긴 단계는 칩에 🔒가 붙고, 눌러도 이동하지 않으면서 무엇이 모자란지 알려 준다.

**세트 잠금은 세트 단위로 독립이다.** SET 1을 끝내지 않아도 상단 메뉴로
어느 세트든 바로 들어갈 수 있다. 한 세트가 늦어져도 연수는 성립한다.

## 화학 내용의 근거

네 시뮬의 완료조건은 모두 헤드리스로 수치 검증했다. 확인한 것:

**SET 2 · 적정** — 매 점의 pH를 조건별 근사식이 아니라 전하 균형식으로 직접 푼다.

* 0.1 M 강산 ← 0.1 M 강염기 당량점 **pH 7.000**
* 아세트산(Ka 1.8×10⁻⁵) 반당량점 **pH 4.745**, pKa 4.745
* 같은 아세트산 당량점 **pH 8.722** (8~9 사이)
* 약산 적정에서 메틸오렌지 → **사용 불가**, 페놀프탈레인 → 사용 가능
* 암모니아 ← 강산 당량점 **pH 5.278** (< 7)

반당량점은 `pH = pKa`보다 소수 셋째 자리 수준으로 아주 조금 높게 나온다.
근사식이 아니라 정확해를 풀기 때문이며, **pH = pKa 쪽이 근사**라는 점을
학생에게 짚어 줄 수 있는 자리다. 교사 노트에 적어 두었다.

**SET 3 · 평형** — 촉매는 `kf`와 `kr`에 같은 배수를 곱하므로 `K = kf/kr`이
수학적으로 변할 수 없다. K는 반트호프 식으로 온도에서만 계산된다.

* 촉매 넣고 빼도 K 0.200 그대로, 도달 시간만 1.53초 → 0.26초
* H₂+I₂⇌2HI 부피 절반 → 압축 직후에도 Q = K = 50.00 (이동 없음)
* N₂O₄⇌2NO₂ 298→400 K → K 0.200 → 72.08, NO₂ 4.12배 (갈색 진해짐)
* N₂+3H₂⇌2NH₃ 700→900 K → K 0.500 → 0.0147 (발열이므로 감소)
* 아르곤은 농도를 건드리지 않으므로 Q 불변
* CaCO₃⇌CaO+CO₂ 에서 K = [CO₂], 고체를 더 넣어도 [CO₂] 불변

**SET 4 · VSEPR** — 결합각은 이상값을 적어 둔 것이 아니라 3차원 좌표에서
내적으로 실측한다. 좌표를 실제 결합각에서 역산하므로 둘이 반드시 일치한다.

* CH₄ 109.5° / NH₃ 107.0° / H₂O 104.5° / BF₃ 120.0° / CO₂ 180.0°
* 같은 사면체 배열에서 고립전자쌍 0·1·2쌍 → 109.5 → 107.0 → 104.5
* 극성은 결합 쌍극자의 벡터합 — CO₂(Δχ 0.89)와 CCl₄(Δχ 0.61) 모두 무극성
* 이중·삼중결합은 영역 하나 — CO₂와 HCN의 전자쌍 영역 수 2
* 회전은 직교 회전행렬이라 결합 길이 오차 6.7×10⁻¹⁶ (부동소수점 한계)

각 시뮬 하단의 **교사 노트**에 보장한 것, 일부러 단순화한 것,
AI가 흔히 내는 오류가 정리되어 있다. 단순화한 가정은 학생에게 반드시 알린다.

## 알아 두어야 할 것

* **강사 코드는 소스에 그대로 있다.** 페이지 소스를 열면 보인다. 진도를 끄는
  편의 장치이지 보안 장치가 아니다. 굳이 찾아보는 연수생은 막지 못한다
* **SET 1 완성본의 API 키 입력칸**은 넣은 키를 브라우저에서 곧바로
  `api.anthropic.com`으로 보낸다. 어디에도 저장하지 않지만, 공용 PC에서는
  왼쪽의 "프롬프트 복사" 쪽을 쓰는 편이 낫다
* **인쇄**하면 지금 보고 있는 쪽이 다섯 단계 모두 펼쳐진 상태로 나온다.
  시뮬레이션 화면과 버튼은 종이에서 빠진다

## 산출물 3종

6 내보내기에서 복사하거나 마크다운으로 내려받는다.

1. **수업계획안 초안** — 워크벤치 목표·기본기 + 선택한 세트의 변형 계획 + 차시 흐름
2. **과정중심 평가도구** — 완료조건에서 펼친 루브릭 + 학생 자기점검 체크리스트 + AI 피드백 프롬프트
3. **지원 디지털 도구 명세** — 사용한 프롬프트 전문 + 완료조건 목록 + 단순화한 가정 + 검증 절차
